The opendis7-java library provides a complete type-safe Java implementation of both the DIS Protocol version 7 (IEEE 1278.1-2012) and SISO-REF-010 Enumerations specifications, interfaces and objects, all as open source.

  • opendis7-java Distribution Products provides a thorough set of prepared assets for project reuse.
  • edu.nps.moves.dis7.pdus package contains all IEEE DIS Protocol Data Unit (PDU) classes.
  • edu.nps.moves.dis7.utilities package contains network interface and data-conversion utilities.
  • edu.nps.moves.dis7.utilities.stream package contains stream utilities for DIS file saving, conversions, and playback.
  • Experimental DIS XML schema and documentation assist with data-centric processing of DIS streams.

Over 22,000 SISO-REF-010 version 37 enumeration values are also provided, autogenerated from the SISO standard.

  • https://www.sisostandards.org/page/ReferenceDocuments (scroll to bottom of page)
  • Complete 2026 assets at siso-ref-010-v37.zip

This release has been prepared by Don Brutzman at Relative Motion Consulting (RMC) on behalf of the Simulation Interoperability Standards Organization (SISO) for the DIS PDG - Distributed Interactive Simulation Version 8 working group (login).

The DIS Product Development Group (PDG) will implement a set of changes to IEEE Standard for Distributed Interactive Simulation—Application Protocols, IEEE Std 1278.1TM-2012 based on the evolving needs and requirements of the current DIS user community. This community is open to SISO Members for a voting membership and to SISO Guest Members to participate in the activities of this community. This community will focus on Problem / Change Requests (PCRs) and Comment Resolutions (CRs). Activities involved with draft standards will limited to voting members of the IEEE Working Group, in order to meet the IEEE Copyright requirements.
